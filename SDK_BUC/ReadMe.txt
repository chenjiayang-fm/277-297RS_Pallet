The note for build code
1. Select Target for application (CU / CAM) and RF type (A7130 / RTC676x / S2019x)
2. Select bsp_select.h for board part number and IC part number
3. Select LCD_TYPE.h for LCD pannel type (SONiX Demo Board can bypass)
4. Select SEN_TYPE.h for Sensor type (SONiX Demo Board for AHD input can bypass)
5. Select APP_CFG_SEL.h for the features config of the application
6. Rebuild all
